# Security Policy

## Supported Versions

No production release exists yet. Security fixes currently target the active development branch.

## Secret Handling

Do not include `api_hash`, phone numbers, auth keys, session keys, bot tokens, 2FA values, proxy credentials, or session database files in issues, logs, tests, fixtures, or commits.

## Reporting

Report suspected vulnerabilities privately through the project maintainers rather than opening a public issue with exploit details.
