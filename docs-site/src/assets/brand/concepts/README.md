# miniproto Logo Concepts

These eight directions implement the approved Wave 5 brand brief. The first four preserve the same marks and ideas as their original inspiration boards. The next four explore other recognizable parts of miniproto: Telegram-compatible delivery, free-threaded Python with a Rust core, quick acknowledgements and multi-source schema generation.

Each family includes a transparent standalone color mark for side-by-side review. A community poll is selecting the permanent identity; concept 03, Packet Loom, is the maintainer-approved provisional website identity while that poll remains open. Its canonical inner SVG is not redrawn during integration and the isolated brand generator keeps a later promotion from requiring content or component restructuring.

## Creative Brief

miniproto is a compact, async-first MTProto SDK whose identity should make speed, protocol correctness, controlled data flow and the Python/Rust relationship feel tangible. The mark must remain serious enough for infrastructure documentation while retaining enough character to be memorable among established Telegram client libraries.

The reference libraries demonstrate the value of one decisive silhouette: Pyrogram's flame and its Kurigram/Pyroblack variants, Hydrogram's droplet, Telethon's `T` and mtcute's flower are recognizable before their wordmarks are read. Each miniproto direction therefore has one primary emblem rather than a scene or collection of unrelated symbols. Packet Plane deliberately alludes to Telegram's familiar delivery metaphor without copying its exact plane path, enclosing circle or visual identity; the other seven avoid the paper-plane motif entirely.

The adjacent `logo.svg` is the canonical color mark for each family on a transparent square canvas, with no wordmark, font, presentation panel or raster content.  
Every `concept.svg` is the canonical presentation board for its family. It consumes the adjacent `logo.svg` directly instead of maintaining an independently redrawn copy, adds accessible presentation metadata and uses a literal SVG `<text>` wordmark backed by an embedded WOFF2 subset. Monochrome samples are deterministic filters of that same source mark. Concepts 01–05 use embedded Nunito Sans ExtraBold at weight 800, while concepts 06–08 use embedded Quicksand SemiBold at weight 600; the complete source fonts, subsets and SIL Open Font License texts are retained in the adjacent `fonts/` directory. The board has no embedded bitmap, network dependency or installed-font dependency. The adjacent `preview.png` is a deterministic Chromium render of `concept.svg` for convenient review because librsvg-based renderers silently substitute embedded webfonts. The adjacent `ideation.png` records the built-in image-generation exploration and is not a production source.

## Review Sequence

1. Compare the standalone marks in the large light and dark panels and ignore provisional palette preferences.
2. Check the monochrome mark. A family that only works through color is not yet robust enough.
3. Inspect the 64, 32 and 16 px samples. The core silhouette should survive even when secondary detail disappears.
4. Decide whether the metaphor represents the whole library or merely one implementation detail.
5. Choose one primary family and, if useful, identify one secondary family whose color, motion or typography should inform refinement.

The strongest family should be recognizable before the `miniproto` wordmark is read, work on light and dark surfaces, remain clear in one color, avoid accidental resemblance to another client library and support a distinctive but readable documentation site.

## Generated Ideation

All eight PNG boards were produced with the built-in image-generation tool using a logo-brand exploration brief. The first four were regenerated from their original boards as image edits, preserving their named silhouettes and ideas while explicitly removing glow, malformed text, geometry drift, mockup effects and inconsistent small-size variants. The next four were generated as new explorations around the Packet Plane, Threadburst, Quick-Ack Comet and Schema Prism metaphors.

Every prompt requested the exact `miniproto` lockup, light and dark presentation, a monochrome treatment and 64/32/16 px samples. The ideation boards remain visual references rather than production sources. The finalized standalone marks come from the approved vectors and the presentation boards render those exact marks alongside real embedded typefaces rather than generated or hand-drawn lettering.
